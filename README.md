# NaturaSì Badge Studio (`nsibadge`)

Generatore web di tessere di riconoscimento aziendali formato standard **CR80 (86 × 54 mm)** fronte/retro pieghevoli conformi al **D.Lgs. 81/2008**.

## File presenti nella repository
- `index.html` — Applicazione completa
- `Logo-bianco.png` — Logo ufficiale bianco NaturaSì
- `lemniscata.png` — Lemniscata ufficiale di sfondo
- `futura-md-bt-medium.ttf` — Font Futura BT Medium
- `futura-bold-bt.ttf` — Font Futura BT Bold
