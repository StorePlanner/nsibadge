# NaturaSì Badge Studio (nsibadge)

Generatore di tessere di riconoscimento aziendali formato standard CR80 (86x54 mm) fronte/retro conformi al D.Lgs. 81/08.

## File presenti nella repository
- `index.html`: Applicazione completa (HTML, CSS e JavaScript integrati in un unico file)
- `Logo-bianco.png`: Logo ufficiale NaturaSì bianco
- `lemniscata.png`: Simbolo lemniscata ufficiale per filigrana
- `futura-md-bt-medium.ttf` e `futura-bold-bt.ttf`: Font ufficiali Futura BT
