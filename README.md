# NaturaSì Badge Studio (nsibadge)

Applicazione web per la generazione e stampa su foglio A4 di tessere di riconoscimento aziendali CR80 (86x54 mm) fronte/retro conformi al D.Lgs. 81/08.

## File nella repository
- `index.html` (Applicazione principale)
- `Logo-bianco.png` (Logo istituzionale bianco)
- `lemniscata.png` (Elemento grafico lemniscata)
- `futura-md-bt-medium.ttf` (Font Futura Medium BT)
- `futura-bold-bt.ttf` (Font Futura Bold BT)
